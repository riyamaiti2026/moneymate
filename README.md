# MoneyMate

A free, private money manager that runs entirely in your browser. Track income and expenses, set a monthly budget, and save towards goals, in **English, Hindi or Bengali**.

**Live site:** https://riyamaiti2026.github.io/moneymate/

## Why I built it
Most money apps need an account, show your data to a server, or only work in English. MoneyMate needs no signup, keeps every rupee of data on your own device, and speaks three languages, so students, homemakers and shopkeepers can all use it.

## Features
- Add, edit and delete income and expenses (with undo)
- Live balance, income, expenses and savings rate
- Monthly budget with a colour-coded progress bar
- Spending-by-category chart and a 6-month income vs expenses chart
- Insights: top category, biggest expense, average spend per day
- Multiple savings goals with a "save this much per month" planner
- Search, filter by type or category, and sort the history
- View any single month or all time
- English, Hindi and Bengali; INR, USD, EUR and GBP
- Light and dark themes
- Export to CSV (Excel), download or restore a JSON backup, print a report
- Works on phones, tablets and computers
- Sample data button for a quick demo

## Built with
HTML, CSS and vanilla JavaScript, plus [Chart.js](https://www.chartjs.org/) for charts. No frameworks and no server.

## Run it locally
1. Download or clone this repository.
2. Open the folder in VS Code and start the **Live Server** extension, or just double-click `index.html`.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure |
| `style.css` | Design, dark mode and mobile layout |
| `script.js` | All the logic: data, charts, translations, export |

## Privacy
All data is stored in your browser's `localStorage`. Nothing is sent anywhere.
